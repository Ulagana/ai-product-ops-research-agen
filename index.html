Headline Macro Patterns & Executive Insights

Synthesized patterns across all 100 apps — skimmable in under 2 minutes.

Auth Dominance 90% Coverage
OAuth2 (52%) & API Keys (38%)

Over 90% of SaaS applications standardize on either OAuth2 or Bearer/Header API keys. OAuth2 dominates user-facing CRM, Support, and Messaging, while API Keys dominate Developer Platforms, Data Scraping, and SEO tools.

Category Friction High Variance
Dev (90% Open) vs. Fintech (50% Gated)

Self-Serve Winners: Developer Platforms & Data/SEO tools offer instant free tier keys.
High Friction: Fintech/Finance (Plaid, PitchBook) & Enterprise CRM (DealCloud, SF Commerce) require manual compliance approval or $20k+ sales contracts.

Primary Blocker 36% Friction
Partner Gating & App Reviews

The #1 barrier to instant toolkit creation is Enterprise Partner Gating (16%), followed by Developer App Review Approval (12%) (e.g. Google Ads, Meta Ads) and No Public API (8%) requiring browser-use/scraping.

Low-Hanging Fruit 64 Apps Ready
64% Instant Agent Buildability

64 out of 100 apps can be turned into production agent toolkits immediately via self-serve credentials without human outreach. Composio can launch toolkits for Developer, Productivity, and Scraping suites with zero partner friction.
